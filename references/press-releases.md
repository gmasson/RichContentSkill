# Press Releases

Lead with the news. Everything else is context.

## Core Rules

- First paragraph answers who, what, where, when, why. No buildup.
- Quotes add authority, not repetition. A good quote contains an insight that isn't already in the lead.
- No unsubstantiated adjectives. "Product with technology X that reduces costs by 30%" — not "revolutionary product."
- End with clear contact details: name, role, email, phone. Link to media assets if available.
- Tone: factual, third-person, no exclamation marks.

## Avoid

- Building suspense before the news.
- Quotes that merely restate what the lead already said.
- First-person language.
- Exclamation marks anywhere in the text.
- Adjectives without data backing them up.

## Structure

```
[Headline] Clear, factual, no puns
[Lead] Who + What + Where + When + Why in 2–3 sentences
[Body] Supporting details, context, background
[Quote] Insight or official position from a named spokesperson
[Boilerplate] About the company — 2–3 sentences
[Contact] Name, role, email, phone, media kit link
```
