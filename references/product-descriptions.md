# Product Descriptions

Lead with the competitive advantage. Follow with specs.

## Core Rules

- First paragraph: the primary problem this product solves and why it solves it better than alternatives.
- Second paragraph: technical details — materials, dimensions, compatibility, certifications.
- Short bullet points for key differentiators, curated ruthlessly. Five strong bullets beat twelve mediocre ones.
- Describe the actual use scenario instead of repeating "this product is perfect for..." across every description.
- Include care or maintenance instructions when relevant. Signals attention to detail.
- For e-commerce: suggest 3–5 related search tags for internal SEO.

## Avoid

- Generic openers that could apply to any product.
- Listing every possible spec without hierarchy.
- Superlatives without substantiation.
- Identical sentence structure across multiple product descriptions.

## Pattern

```
Advantage hook (what problem it solves, why better)
→ Specs (materials, dimensions, compatibility)
→ Differentiators (3–5 curated bullets)
→ Use scenario (who uses it, when, how)
→ Care instructions (if applicable)
→ SEO tags (if e-commerce)
```
