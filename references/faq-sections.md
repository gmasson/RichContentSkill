# FAQ Sections

Write questions the way users ask them.

## Core Rules

- Natural language: "How do I cancel my subscription?" — not "Cancellation procedure."
- Answers: complete but direct. Numbered steps for processes. Links to detailed docs for complex topics.
- Group by theme so readers scan to their relevant category.
- Living document: add new entries as questions recur. Never rebuild from scratch for one addition.

## Avoid

- Jargon in question titles.
- Answers that begin with "Great question!" or similar filler.
- Single-paragraph answers that could be broken into clear steps.
- Orphan questions that don't belong to any category.
